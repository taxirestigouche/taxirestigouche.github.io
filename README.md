# Taxi Restigouche

Appli web installable (client, chauffeur, centrale) pour Taxi Restigouche — Campbellton, Listuguj, Pointe-à-la-Croix, Dalhousie et la région.

- `index.html` : connexion (téléphone + NIP)
- `client.html` : commander, suivre son taxi, courses et factures, compte
- `chauffeur.html` : punch in/out, offres, compteur virtuel, journée, messages, dossier
- `centrale.html` : répartition en direct, appels, rapports, chauffeurs, clients, tarifs, comptes, messages

Base de données : Supabase (projet « Taxi Restigouche », Canada). Cartes et adresses : OpenStreetMap.
